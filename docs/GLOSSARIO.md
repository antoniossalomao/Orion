# Glossário

| Termo | Significado |
|---|---|
| **Vault** | Pasta de notas Markdown (Obsidian) que serve de memória do Orion |
| **Núcleo imutável** | `orion-policy`, `REGRAS.md` e a persona: o agente não os altera |
| **Classe de risco** | Nível que decide se uma ferramenta roda sozinha, pede aprovação ou é bloqueada |
| **Modo autônomo** | Execução sem aprovação a cada passo; pede a senha ao ligar |
| **Pânico** | Atalho que corta voz, ferramentas e tarefas em andamento (Ctrl+Alt+P) |
| **Mini barra** | Ilha de voz no topo da tela (Ctrl+Alt+Espaço) |
| **Isso?** | Captura rápida que pergunta ao Orion sobre o que está na tela |
| **Gateway** | Camada que escolhe entre provedores gratuitos de IA e controla cotas |
| **CLIs oficiais** | Claude Code e Codex usados como motor de nuvem, opt-in |
| **Worker llama** | `orion-llama.exe`, processo que carrega modelos GGUF locais |
| **Céu / constelação** | Fundo animado do instalador e do onboarding (`orion-sky`) |
| **Cinturão** | Alnitak, Alnilam e Mintaka: as três estrelas do meio da constelação |
| **Setup** | `Orion Setup.exe`, o instalador |
| **Spike** | Experimento curto que mede um risco e termina em uma decisão escrita |
| **v1** | Marco M1, fases F01–F10 |
